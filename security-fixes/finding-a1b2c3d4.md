# Security Finding: Broken Object-Level Authorization on Orders API

**Severity:** HIGH  
**Status:** open  
**Finding ID:** `a1b2c3d4-0008-4008-8008-000000000008`  

**Affected Component:** Orders Service  
**API Endpoint:** `GET /api/v1/orders/{order_id}`  
**File Location:** `backend/app/api/orders.py:55`  
**CWE:** CWE-639  
**CVSS Score:** 8.1  

## Description

The GET /api/v1/orders/{order_id} endpoint returns full order details (including payment info and PII) without verifying that the requesting user owns the order. Enumeration of sequential order IDs reveals other customers' data.

## Vulnerable Code

```
@router.get('/orders/{order_id}')
async def get_order(order_id: int, current_user=Depends(get_current_user)):
    order = await order_service.get(order_id)
    # Missing: if order.user_id != current_user.id: raise HTTPException(404)
    return order
```

## Remediation

Add ownership verification: assert order.user_id == current_user.id before returning data. Return 404 (not 403) to avoid confirming existence. Use UUIDs instead of sequential integers for order IDs to reduce enumeration risk.
