## Description

The search endpoint at /api/v1/search reflects the user-supplied 'query' parameter directly into the HTML response without encoding. An attacker can craft a malicious URL that executes arbitrary JavaScript in the victim's browser.

## Vulnerable Code

```
return HTMLResponse(content=f'<h1>Results for: {query}</h1>' + results_html)
```

## Remediation

HTML-encode all user-supplied values before rendering them in the response. Use a templating engine with auto-escaping (e.g., Jinja2 with autoescape=True). Implement a strict Content-Security-Policy header.
